Entrenamiento v4 en vivo

Cada lote genera un dataset v4 sellado (8 familias geométricas; TEST con SHA-256 y auditoría anti-contaminación), añade su TRAIN a la CDT de vigilia, consolida un teacher y ajusta Dφ con la receta §16 (cabeza local-lineal con compuerta H136 + replay de confianza τ=1 %). La CDT y el teacher se descartan antes de evaluar el TEST del lote; cualquier consulta a memoria en TEST se marca LEAKED. Cada lote guarda un checkpoint bit-exacto de Dφ.

    palabras: tokens leídos por el crawler (incluye etiquetas y marcadores). forks: palabras/números evaluados. code: p ≥ umbral, resueltas sin modelo. llm: escaladas al LLM (p < umbral). tú: ruta final humana (pide aprobación o el LLM no resolvió).
    
              
    p: confianza heurística de la pregunta más dudosa (o la del LLM si resolvió). media: promedio de la p final de todos los forks.
    
              
    cobertura: % del prompt leído, no resuelto. corrida corta: máx. N escaladas; el resto queda pendiente con «límite de corrida corta».
    
              
    Si la API externa (docker-llm) no responde, se usa Gemma local (respaldo). Un fallo nunca inventa: la palabra queda pendiente con el motivo.
