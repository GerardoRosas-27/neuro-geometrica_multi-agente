# Soft-Bellman v1 — preregistration

Written before implementation/DEV. Standalone Rust crate; existing application untouched.
Source: https://share.gemini.google/z2Ff8ZASj74L (equations supplied in reviewed proposal).

## Architecture and finite experiment
Transition cost c(x,u)=1+sqrt(epsilon+softplus(w_axis·f(x))²)+softplus(w_phi·f(x+u)); epsilon=.01, f=[1,a,b]. G is diagonal SPD; axis 0 has one metric head, all other axes share a second head. Nine learned scalar parameters. Phi is nonnegative. This is a restricted diagonal/tied-metric version, NOT full Cholesky or a language model.
Soft minimum at tau=.2, stable logsumexp, finite horizon H=number of cells. V0(goal)=0; other states infinity. Goal is absorbing/clamped zero at every layer; unreachable states stay infinity. Differentiate oracle-action NLL analytically through all unrolled layers. Positive transition floor exceeds tau log(6), avoiding entropy-induced negative cycles for tested degrees; finite horizon remains mandatory.

## Data, controls, fixed configuration
Synthetic inverse planning, not discovery of physical laws. Observable terrain features a,b in [0,1], 18% independent obstacles, random goal; deterministic oracle Dijkstra with a fixed nonlinear hidden teacher cost law of the same family. Oracle weights are only in generator/evaluation, never model input. Each map uses independently derived RNG streams; no map shared across train/validation/test. Regenerate disconnected maps; retain all reachable non-goal states. Terrain is supplied, true edge costs and oracle values are NOT inputs. Teacher labels are deterministic optimal actions; tie-breaking fixed.
Per seed: 24 training maps, 8 validation maps, 64 held-out maps, 6x6 2D; 16 held-out 3x3x3 3D maps (dimension OOD, tied axes). Train on all reachable states, average first within map then across maps. Full-batch Adam, 160 updates, learning rate .03, beta1=.9 beta2=.999 epsilon=1e-8; no checkpoint selection, final update used. Random normal initialization scale .15; global gradient clip 10. Validation descriptive only, no retuning. Uniform-cost planner and untrained identical-initialization planner controls. Reactive shared MLP control (8 features, 8 tanh units, 81 parameters) trained on identical examples/updates/optimizer; explicitly NOT compute- or parameter-matched, and no global obstacle propagation. It is an auxiliary baseline, not evidence of universal superiority.
No hyperparameter sweep. A negative or mixed result is acceptable. Changes needed for correctness are documented; cannot tune on CONFIRM.

## Seeds/statistics/criteria
DEV 0xA400–0xA40F, then freeze implementation/config, CONFIRM 0xB400–0xB40F, 16 independently initialized/trained models each. Per-seed disjoint map streams. Primary: held-out 2D path relative regret (true route cost / oracle cost - 1), average over all reachable starts. Greedy policy uses decreasing horizon; failure penalized regret=5 (report failure separately). Paired bootstrap seed means, 10000 resamples, RNG seed12345, percentile 95% CI (delta=.05), learned minus each control. Accept benefit over constant metric ONLY if upper CI <0 on CONFIRM and success does not decrease. Report untrained improvement, MLP comparison, action NLL, optimal-action accuracy, success, regret and 3D transfer separately. No multiplicity-adjusted claims; all nonprimary comparisons exploratory.

## Correctness and stop rules
Unit tests: softmin extremes, SPD/positive costs, absorbing goal, unreachable state, generic dimension, analytic gradients vs central finite differences, oracle cost sanity, deterministic RNG/replay. Confirm each meaningful trained parameter against finite differences; gradient relative/absolute tolerance 1e-5. Check finite losses/parameters; stop on NaN, failed checks or >45 minutes total training. At most 4 workers, nice -n10, build jobs2. Save per-seed metrics, trained weights, route examples and raw epoch logs; machine-readable output plus Spanish report and exact commands/wall time. Finish bounded task rather than leave hidden background jobs.
